# مرکز عملیات بات‌ها

این پوشه مرجع مشترکِ کارهای بات‌های پروژهٔ رستوران فندوق است. خروجی‌های پایدار، تصمیم‌ها و گزارش هر کار باید فقط در همین مسیر ذخیره شوند.

## ساختار

- `logs/` — گزارش فعالیت هر بات، در فایل مستقل خودش
- `reports/` — گزارش‌های ممیزی، معماری و جمع‌بندی مدیریتی
- `docs/` — اسناد مرجع و تاریخی پروژه
- `INVENTORY.md` — نقش‌ها، مسیرها، منابع واحد و مهارت‌های فعال

مهارت‌های تیم در `.agents/skills/` نگهداری می‌شوند (منبع واحد)؛ این پوشه جای کپی مهارت نیست.

## قاعدهٔ ثبت

هر ورودی گزارش شامل تاریخ و ساعت، درخواست یا هدف، اقدام انجام‌شده، فایل‌های تغییرکرده و وضعیت نهایی است. اطلاعات محرمانه (گذرواژه، توکن، کد یک‌بارمصرف و دادهٔ شخصی غیرضروری) هرگز ثبت نمی‌شود.

## قاعدهٔ تغییر کد

- تغییر رفتار افزونه فقط با درخواست صریح مالک پروژه انجام می‌شود؛ بازبینی به‌تنهایی مجوز اصلاح نیست.
- پیش از تحویل، `php -l` روی فایل‌های تغییریافته و سپس `python tools/build-release.py` اجرا شود.
- بستهٔ نصب فقط از مسیرهای مجاز ساخته می‌شود؛ فایل توسعه، مهارت و مستند داخلی وارد ZIP نمی‌شود.

این پوشه برای مستندسازی و خروجی‌های پروژه است؛ تنظیمات داخلی خود سامانه یا تاریخچهٔ فنی اجرای مدل که خارج از پروژه نگهداری می‌شود قابل انتقال نیست.
