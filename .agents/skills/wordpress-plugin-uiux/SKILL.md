# WordPress Plugin + UI/UX

## پیش از پیاده‌سازی

- ساختار فعلی افزونه، نسخه‌های WordPress/PHP، وابستگی‌ها و افزونه‌های هم‌پوشان را بررسی کن.
- معماری را با پیشوند/namespace یکتا، bootstrap کوچک، ماژول‌های جدا و مسیر حذف پاکیزه طراحی کن.

## ایمنی و داده

- برای ورودی‌ها nonce، capability، sanitize، validate و escape خروجی را رعایت کن.
- برای AJAX یا REST، permission callback و پاسخ خطای قابل‌اقدام داشته باش.
- از APIهای WordPress استفاده کن؛ query سفارشی را آماده‌سازی کن؛ migration داده را نسخه‌دار و قابل بازگشت نگه دار.

## UI/UX

- از الگوهای بومی مدیریت وردپرس استفاده کن: عنوان روشن، گروه‌بندی منطقی، راهنمای کوتاه، وضعیت ذخیره، خطای قابل‌فهم و حالت خالی/بارگذاری/خطا.
- RTL فارسی، موبایل/دسکتاپ، کنتراست، focus صفحه‌کلید، label فرم، متن بلند و حداقل اندازهٔ لمس را بررسی کن.
- هنگام طراحی رابط، مهارت `ui-ux-pro-max` را نیز بخوان و اجرا کن.

## Elementor و کنترل کیفیت

- فقط از APIهای سازگار Elementor استفاده کن و بدون نیاز قطعی وابستگی به Pro ایجاد نکن.
- نصب تازه، ارتقا، فعال‌سازی/غیرفعال‌سازی، حذف، نقش‌های کاربری، خطاهای PHP و مسیرهای اصلی را پیش از تحویل تست کن.

## ثبت پروژه

همهٔ خروجی‌ها زیر `E:\رستوران فندوق` می‌مانند. پس از هر کار، تاریخ، هدف، فایل‌ها، تست و نتیجه را در `E:\رستوران فندوق\bot-operations\logs\motahari.md` ثبت کن. رازها را ثبت نکن.
