# ظاهر منو و CSS اختصاصی — نسخه ۱.۳.۰

از پنل اختصاصی `/cafe-panel/` وارد «تنظیمات ← ظاهر منو» شوید. تغییرات فرم تا زدن دکمه «ذخیره تنظیمات» روی منوی عمومی ذخیره نمی‌شوند. پیش‌نمایش با یک مسیر جداگانه اعتبارسنجی می‌شود و داده‌های تنظیمات، محصولات یا سفارش‌ها را تغییر نمی‌دهد.

## طرح‌های آماده

| طرح | ظاهر پیشنهادی |
|---|---|
| کافه | زمینه گرم، رنگ قهوه و کارت‌های نرم |
| مینیمال | زمینه روشن، آبی و خطوط ساده |
| نیمه‌شب | زمینه تیره، رنگ مسی و کنتراست خوانا |
| باغ | زمینه روشن، سبز و گوشه‌های نرم |
| بیسترو | رنگ قرمز، زمینه کرم و ظاهر پرانرژی |

انتخاب طرح، رنگ‌های پیشنهادی را در فرم قرار می‌دهد. پس از انتخاب می‌توانید رنگ‌ها، فونت، اندازه و وزن متن و چیدمان شبکه‌ای/فهرستی را تغییر دهید. محتوای غذاها، ترجمه‌ها، قیمت، سفارش‌ها و CSS نوشته‌شده حفظ می‌شوند. ارتقا از نسخه قبلی به‌صورت پیش‌فرض همان طرح کافه و رنگ‌های ذخیره‌شده را نگه می‌دارد.

## باکس‌های اختصاصی عناصر

در باکس هر عنصر فقط ویژگی و مقدار CSS بنویسید؛ نام کلاس و آکولاد لازم نیست:

```css
border-radius: 22px;
box-shadow: 0 8px 24px rgb(0 0 0 / 8%);
border: 1px solid #e8dfd6;
```

| باکس | عناصر هدف |
|---|---|
| کارت غذا | `.ac-product` |
| جزئیات غذا | `.ac-food-dialog` |
| انتخاب زبان | `.ac-language-dialog` |
| دسته‌بندی‌ها | دکمه‌های `.ac-categories` |
| دکمه‌ها | `.ac-primary`، `.ac-plus` و `.ac-cart-float` |
| سبد سفارش | `.ac-cart-dialog` |

می‌توانید یک باکس را پاک کنید یا CSS اختصاصی را موقتاً غیرفعال کنید؛ غیرفعال‌سازی متن باکس‌ها را پاک نمی‌کند. CSS معتبر پس از استایل پایه و طرح آماده اعمال می‌شود. انتخابگرهای خاص‌تر یا `!important` در صورت نیاز قابل استفاده‌اند.

## باکس CSS عمومی

در این باکس قواعد کامل با انتخابگرهای داخل منو وارد کنید:

```css
.ac-product h3 {
  color: #6d4938;
  letter-spacing: 0;
}
.ac-categories button.active {
  border-radius: 12px;
}
@media (max-width: 640px) {
  .ac-product { border-radius: 16px; }
}
```

سرور انتخابگرها را به محدوده منو متصل می‌کند؛ نوشتن انتخابگر اصلی سایت یا پیشوند پنل لازم نیست. در باکس عمومی می‌توانید حالت‌های `:hover`، `:focus-visible`، `::before`، فهرست انتخابگرها، متغیرهای CSS و قواعد `@media` و `@supports` را به کار ببرید. برای تنظیم متغیر روی ریشه خود منو از `.ac-menu` استفاده کنید.

CSS فقط روی منو و اجزای آن، چه صفحه مستقل و چه شورت‌کد یا صفحه‌ساز، اعمال می‌شود. پرداخت بومی ووکامرس و محتوای اطراف منو با تنظیمات قالب یا صفحه‌ساز طراحی می‌شوند. پیش‌نمایش در محدوده جداگانه‌ای قرار دارد تا متن CSS ظاهر پنل مدیریت را تغییر ندهد.

## اعتبارسنجی و محدودیت‌ها

قواعد CSS و مقدارهای باکس‌ها هنگام پیش‌نمایش و ذخیره در سرور بررسی می‌شوند. متن نامعتبر با پیام خطا رد می‌شود و تنظیمات ذخیره‌شده قبلی باقی می‌مانند. پیش‌نمایش در صورت خطا آخرین CSS معتبر را نمایش می‌دهد؛ متن در حال ویرایش حفظ می‌شود.

ورود HTML یا JavaScript، آدرس منابع با `url()`، `@import`، `@font-face`، `@keyframes`، انتخابگرهای سراسری مثل `html`/`body`/`:root` و قواعد تو در تو به سبک nesting پشتیبانی نمی‌شوند. فونت و تصاویر را از بخش‌های مخصوص افزونه تنظیم کنید. CSS escape و دستورهای قدیمی مثل `expression()` یا `behavior` نیز پذیرفته نمی‌شوند. برای قواعد واکنش‌گرا از `min-width` و `max-width` استفاده کنید؛ نگارش مقایسه‌ای با `<` پشتیبانی نمی‌شود. متغیرها برای ویژگی‌های شناخته‌شده مثل `color`، `background-color`، اندازه و فاصله مجازند؛ در ویژگی‌های تصویر یا ناشناخته مقدار مستقیم لازم است.

حداکثر متن باکس عمومی ۱۲٬۰۰۰ بایت، هر باکس عنصر ۴٬۰۰۰ بایت و مجموع باکس‌ها ۳۰٬۰۰۰ بایت است. ساختار و نوع مقادیر نیز بررسی می‌شوند. برای استایل‌ها از ویژگی‌های استاندارد CSS استفاده کنید؛ CSS سفارشی می‌تواند خوانایی یا اندازه عناصر را تغییر دهد، بنابراین حالت موبایل، زبان فارسی و یکی از زبان‌های چپ‌به‌راست را در پیش‌نمایش بررسی کنید.
