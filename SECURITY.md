# Security

The currently maintained version is 1.3.1. Older snapshots are retained for
diagnosis and rollback; retention is not a promise of security maintenance.

Report vulnerabilities privately through GitHub's **Report a vulnerability**
button when available. If it is unavailable, contact the repository owner using
a private channel already known to you; do not publish credentials or exploit
details in a public issue. No private contact address is currently configured.

Include affected versions, reproducible steps, impact and a minimal redacted
example. Keep real customer data, access tokens, translation keys, databases and
payment information out of reports. No response-time guarantee is specified.

Tests use disposable data. Gateway, browser Push and translation provider tests
must use controlled accounts and explicit target-environment configuration.
